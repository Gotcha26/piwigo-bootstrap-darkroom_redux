# Bootstrap Darkroom (redux)

A maintained fork of [Bootstrap Darkroom](https://github.com/Piwigo/piwigo-bootstrap-darkroom)
by Thomas Kuther, carrying fixes that have not yet landed upstream.

Free, and not sold anywhere. Its home is the public repository below; corrections made here are
proposed back to the original project whenever they are of general interest.

## Installation — read this first

This theme is a **drop-in replacement**. It installs into `themes/bootstrap_darkroom`, the same
directory as the original, and deliberately keeps the same theme id.

That is what makes the switch transparent: your gallery keeps its theme selection, its settings
and its child themes, with nothing to reconfigure. It also means the two cannot coexist — this
fork takes the place of the official theme.

Keep a copy of your current `themes/bootstrap_darkroom` outside of `themes/` before switching, so
you can go back.

## Updates

This theme is not listed in the Piwigo extension repository, so Piwigo will never offer to update
it — and, importantly, will never overwrite it with the official release. Updates are fetched from
the repository below.

## Requirements

Same as the original theme. Nothing else is needed.
